# 规格定义（配置化）

把「目标像素、裁切框、留白、对齐点、内容安全区、九宫格边距」写成配置项，保证批量产出风格统一、方便接手。

## 一、配置文件格式（JSON）

```json
{
  "canvas": { "width": 1024, "height": 1024 },
  "crop": { "mode": "trim_transparent" },
  "padding": { "top": 24, "right": 24, "bottom": 24, "left": 24 },
  "align": { "anchor": "center", "baseline": "center" },
  "safe_area": { "inset": 0.05 },
  "nine_grid": { "rows": 3, "cols": 3, "guides": true },
  "scale_policy": "contain"
}
```

## 二、字段语义

| 字段 | 含义 | 易混淆点 |
|---|---|---|
| `canvas` | 目标画布像素 | — |
| `crop.mode` | `trim_transparent` 裁透明空边 / `none` 不裁 | **裁透明空边 ≠ 去掉素材黑底** |
| `padding` | 外侧留白（画布内、元素外） | **外侧留白 ≠ 内部内容安全区** |
| `safe_area.inset` | 内部内容安全区（元素内部留白） | 文字/徽章不能越此线 |
| `nine_grid` | 九宫格边距，标记伸缩/固定区 | **切成九份 ≠ 拉伸后不变形** |
| `scale_policy` | `contain` 等比适配 / `cover` 裁切填充 / `stretch` 拉伸（禁用） | 固定装饰保形，伸缩区要测试 |

## 三、⚠️ 三个最易混淆的边界

1. **裁透明空边 ≠ 去掉素材黑底**
   前者只裁 PNG 的透明外框；后者是抠图去背景，需求完全不同。误做会把黑底当内容留下。

2. **外侧留白 ≠ 内部内容安全区**
   外侧留白是元素与画布边界的距离；内容安全区是元素内部留给文字/徽章的余量。两者都要有，不能互相替代。

3. **切成九份 ≠ 拉伸后不变形**
   九宫格切分只标注可伸缩区；拉伸时固定装饰（头像框边角、名牌徽章）必须保形，中间区域才可伸缩。**为铺满而拉伸是最常见的返工原因。**

## 四、标准处理链（规格落位）

```
取单件 → 裁透明空边 → 等比适配 → 留白对齐 → 安全区检查 → 交付
```

- 等比适配：使用 `contain`，**保住完整轮廓，不拉伸**
- 留白对齐：按 `align.anchor` 居中，偏移按 `padding` 四边分别计算
- 固定装饰保形，伸缩区域单独测试（含极端长文本、深浅背景）

## 五、交付前自检清单

- [ ] 图层/元素无偏移
- [ ] 尺寸比例未变化
- [ ] 图层顺序正确（背景层最底）
- [ ] 无白底/黑底残留
- [ ] 无元素误删
- [ ] 透明边缘无白边（适当柔化）
- [ ] 文字、图表、装饰元素均可单独编辑
- [ ] 长文本 / 深浅背景 / 引擎实装分别测过
